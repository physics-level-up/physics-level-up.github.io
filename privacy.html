Privacy policy: levelup-youtube uploader

Effective 12 October 2026

The levelup-youtube uploader ("the tool") is a command-line program that uploads the video lessons of levelUP physics to the levelUP physics YouTube channel. It is run only by the owner of that channel, on the owner's own computer. It has no website, no server and no other users.

YouTube API Services

The tool uses YouTube API Services. By using it, the channel's owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

When the channel's owner signs in with Google and grants permission, the tool can:

  • upload videos to the owner's YouTube channel;
  • set the title, description, category and privacy setting of a video it uploads;
  • attach caption files to those videos;
  • read the name and identifier of the owner's channel, to confirm that it is signed in to the right channel.

The tool does not read the data of viewers, subscribers, commenters or any other person.

What the tool stores

The tool stores two files on the owner's computer, and nowhere else:

  • the authorization token that Google issues at sign-in, so that the owner does not have to sign in before every upload;
  • a list of the videos the tool has uploaded: each video's identifier, address, title, privacy setting and upload date.

What the tool shares

The tool sends data only to YouTube, through YouTube API Services, and only the videos, captions and descriptions that the owner chooses to upload. It does not send data to any other party. It does not collect analytics, set cookies or show advertising.

Deleting stored data and revoking access

The stored files can be deleted from the owner's computer at any time. Access can be revoked at any time on Google's security settings page, security.google.com/settings/security/permissions. After access is revoked, the stored token no longer works.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
